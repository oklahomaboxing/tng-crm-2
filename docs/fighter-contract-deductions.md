# Fighter contract deductions

Open **TNG BOXING EVENTS → event → Contracts**. Every bout has visible **Deductions · [fighter]** buttons above its expandable details. The button uses the current contract revision. Generate a contract first if no contract exists.

1. Open the fighter’s deductions.
2. Add **Blood work**, **Hotel**, or **Other deduction** and enter each amount.
3. Review existing contract deductions, the itemized charges, and projected net payout.
4. Click **Save deductions**. Reopen to edit or remove an added charge.
5. Download the saved payout deduction statement PDF.

Projected payout is gross purse plus travel allowance and recorded per diem, less existing and added deductions. Ticket commissions are separate. Saving a draft updates its original deduction/payout fields, which the existing contract PDF uses. Regenerating a draft retains the saved itemized deduction total. Existing unitemized contract deductions remain separately visible and are not double counted.

Sent/signed agreements, uploaded signed PDFs, signature records, and existing signed contract fields stay unchanged. Charges against those contracts are attached payout records and a separate statement, rather than a rewritten signed agreement. The statement does not attest that payment was made or that an amendment was signed. This feature does not charge a card, pay a fighter, or send email/SMS.

Staff with existing contract access can maintain deductions. Every save is audited. Version checks prevent stale edits from replacing newer changes; reload after a conflict. Negative/nonfinite/sub-cent amounts and deductions exceeding available contractual payout are rejected. Statement downloads are authenticated and not cached publicly.
