# TNGOS workspace upgrade

The shared staff workspace now applies to every role-allowed module: gym and members, check-in administration, boxing and events, retail and sales, communication and marketing, and administration.

## Everyday use

- Choose **Modules** in the top bar or **All modules & layout** in the sidebar to browse/search the entire operation.
- Quick tasks open member profiles, ticket sales, fighter contracts, paid purses/commissions, renewal notices and the text inbox, according to role. Event tasks ask you to choose an event if one is not open.
- Pin up to eight workspaces. Pins appear in the sidebar and in the module center. Recent workspaces are remembered automatically.
- Choose **Layout settings** in the module center to switch between **Comfortable / Compact** density or enable **Focus layout** to hide workspace guidance. Changing layout keeps the current module mounted, preserving in-progress form state.
- Standard / Command modes remain available. Mode and workspace preferences persist across logout on this browser. Preferences contain module names and layout choices, not authentication tokens, member data or event records.
- Every module has a short purpose statement and links to related tools. Copy workspace link copies a workspace URL, not a login token or private record URL.
- Event cards offer direct Fight card, Tickets, Contracts and (admin/staff only) Purses & recap entry points. Event section links are bookmarkable and validated by role. Backend permissions still apply independently.

## Shared interface

Consistent tables, tabs, dialogs, menus, spacing and touch targets; scrollable table containers; mobile module cards; keyboard access; reduced-motion support; print styles; a skip-to-workspace link; and a browser-offline warning. The offline warning does not claim server health or queue changes for later saving.

Kiosks, public checkout, signup and customer portals retain their dedicated routing. No charges, payments, contract signatures, membership statuses, attendance or outbound messages are created by the workspace controls. Existing financial warnings and reporting deadlines remain visible even in Focus layout.

Preferences are per browser and role. They do not grant access, follow a user to another device, or synchronize business records. Clearing browser storage resets them.
